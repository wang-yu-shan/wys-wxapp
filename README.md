# 微信小游戏集合

包含两个小游戏：

- 五子棋（人机对战，简单 AI）
- 俄罗斯方块（触控操作）

## 运行方式

1. 使用微信开发者工具导入本目录。
2. 项目类型选择 **小游戏**。
3. 运行后可在主菜单选择游戏。

## 操作说明

### 五子棋
- 点击棋盘空位落子。
- 黑子（玩家）先手，白子（AI）后手。
- 任意一方先连成 5 子即获胜。

### 俄罗斯方块
- 左下 `←` / `→`：左右移动
- 中下 `旋转`：旋转方块
- 右下 `↓`：加速下落
- 右上 `返回`：回到主菜单


## 导入注意

- 如需运行五子棋和俄罗斯方块，请在微信开发者工具中按 **小游戏** 类型导入（入口：`game.js`）。
- 若误按 **小程序** 类型导入，本仓库也提供了最小可运行的 `app.json` 与示例页面，避免出现“项目根目录未找到 app.json”的报错。
